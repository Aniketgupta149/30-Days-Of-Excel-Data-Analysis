# 📊 Day 01 - Excel Basics

## 🎯 Objective

Understand the Excel interface, basic operations, and data handling.

---

## 📌 What is Excel?

Microsoft Excel is a spreadsheet tool used for storing, organizing, and analyzing data using rows and columns.

---

## 🧱 Key Components

### 🔹 Workbook

A file that contains multiple sheets.

### 🔹 Worksheet

A single page inside a workbook.

### 🔹 Rows & Columns

* Rows → Horizontal (1,2,3...)
* Columns → Vertical (A,B,C...)

### 🔹 Cell

Intersection of row and column (Example: A1)

---

## 🛠️ Basic Operations

### ✅ Data Entry

* Enter text, numbers, dates

### ✅ Formatting

* Bold, font size, color
* Adjust column width

### ✅ Sorting

* Sort A → Z or Z → A

### ✅ Filtering

* Filter data based on conditions

---

## 📊 Tables (Important)

Convert data into table:

1. Select data
2. Press **Ctrl + T**
3. Click OK

### Benefits:

* Automatic formatting
* Easy filtering
* Structured references

## 🧪 Practice Task

Create a dataset like:

| Name | Age | Marks |
| ---- | --- | ----- |
| A    | 20  | 80    |
| B    | 22  | 75    |
| C    | 19  | 90    |

### Tasks:

* Convert into table
* Apply sorting (Marks high to low)
* Apply filter (Marks > 80)

---

## 💡 Key Takeaways

* Excel is used for data organization and analysis
* Tables are very powerful
* Sorting & filtering are basic but important tools
